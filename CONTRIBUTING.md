# Contributing to NovaMC

## Workflow

Use `development` for active repair work and `main` for release-ready changes.

1. Inspect and reproduce the issue.
2. Make the smallest safe root-cause fix.
3. Add or update a meaningful test when practical.
4. Run build and regression checks.
5. Document blocked runtime checks honestly.
6. Keep secrets and runtime data out of Git.

Never mark an untested feature as production-ready.
